# الإشراف والتأهيل التربوي — البرنامج الأسبوعي (PWA)

تطبيق ويب تقديمي (PWA) لنفس وظائف تطبيق «البرنامج الأسبوعي للمشرف التربوي» الأصلي، بواجهة عربية RTL، يعمل على الهاتف والكمبيوتر، ويُثبَّت على شاشة الرئيسية على iPhone/iPad وAndroid وWindows.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الواجهة (RTL): الترويسة، شريط الحالة، المشرف، الأيام الستة، الملاحظات، الكود، النوع، الأزرار |
| `app.js` | كامل المنطق: تحميل القوائم، اختيار المشرف/المدارس/الفعاليات، التحقق، البحث، الحفظ، المشاركة، الكاش |
| `styles.css` | الهوية البصرية (كحلي `#1B2A4A` + تركوازي `#1F7A8C`) + التصميم المتجاوب |
| `sw.js` | عامل الخدمة: تخزين الواجهة للعمل دون اتصال + كاش بيانات Google |
| `manifest.webmanifest` | بيانات التثبيت (الأيقونة، الاسم، الوضع المستقل) |
| `icons/` | أيقونات 180/192/512 + أيقونة قابلة للقص (maskable) |
| `tools/gen_icons.py` | سكربت توليد الأيقونات (Pillow) |

## التشغيل محلياً

```bash
npx serve .            # أو أي خادم ثابت آخر
python -m http.server 8123   # بديل (لاحظ ملاحظة الـ MIME أدناه)
```

> **مهم لعامل الخدمة (sw.js):** يجب أن يُقدَّم `sw.js` و`app.js` بنوع MIME صحيح
> (`text/javascript` أو `application/javascript`). بعض خوادم Python القديمة ترسل
> `text/plain` فيرفض المتصفح تسجيل عامل الخدمة. كل خدمات الاستضافة الشهيرة
> (GitHub Pages, Netlify, Vercel, IIS) ترسله صحيحاً.

## النشر

يُنشر كمجلد ثابت على أي خدمة تعمل بـ **HTTPS** (شرط لعامل الخدمة والتثبيت):

1. ارفع المجلد كما هو إلى GitHub Pages / Netlify / Vercel / أي استضافة.
2. افتح الرابط في Safari على iPhone.
3. شاركة ← «إضافة إلى الشاشة الرئيسية».
4. على Android/الكمبيوتر: سيظهر زر «تثبيت» داخل التطبيق تلقائياً.

## الوظائف (مطابقة للتطبيق الأصلي)

- تحميل قوائم: المدارس (عمود 2)، الفعاليات (عمود 3)، المشرفون (عمود 4) من ملف CSV، مع تجاهل الفراغات وإزالة التكرار مع الحفاظ على الترتيب.
- الفترة الأسبوعية تُحسب من صف السطر السحري `(اخترمن القائمة)اسم المشرف`.
- اختيار المشرف عبر قائمة بحث، وآلة حالة الإرسال المزدوج (عدّاد الإرسال مسبقاً / تحذير مزدوج) بنفس تسلسل التطبيق الأصلي بالضبط.
- ستة أيام (الأحد… السبت): مدرسة + فعالية لكل يوم، مع علامة ✓ عند اكتمال اليوم.
- التحقق العشري بنفس رسائل الخطأ وترتيبها.
- البحث بالمشرف + الكود: يستعيد آخر صف مطابق (المدارس بالتناوب، الفعاليات بالتناوب، الملاحظات، النوع) ويعرض صفوف النتائج.
- الحفظ: يرسل `GET` إلى `formResponse` بنفس ترتيب المعاملات الـ16.
- مشاركة نصية (Web Share أو نسخ للحافظة)، تحديث القوائم، كاش محلي (localStorage).

## التركيب والقيود

- **الحفظ عبر `no-cors`**: المتصفح لا يسمح بقراءة رمز استجابة Google Forms من نطاق آخر، لذلك يُعتبر «الإرسال ناجحاً» إذا تم تنفيذ الطلب فعلياً، ولا يمكن التحقق من رمز 200. (التطبيق الأصلي كان يقرأ الاستجابة داخل تطبيق أصلي بلا قيود CORS.)
- لا إشعارات push، ولا كاميرا، ولا دخول/حساب — مطابقاً للأصل (لم تكن موجودة أصلاً).
- أول تشغيل يحتاج إنترنت؛ بعده تعمل الواجهة والقوائم المحفوظة دون اتصال (البيانات الجديدة تحتاج اتصالاً).
- لا توجد أي مفاتيح أو سرور — كل شيء في المتصفح.

## الاختبار

تم التحقق آلياً (Puppeteer ضد Edge، 390×844 و768×1024):

- لا تجاوز أفقي في أي مقاس، البطاقات 12px من الحواف.
- 6 أيام بالعناوين الحرفية نفسها، الفترة من CSV الحيّ.
- الأوراق (Sheet) مع البحث التصفية، اختيار مدرسة/فعالية/مشرف مع رسائل الحالة.
- التحقق الكامل (اسم المشرف، الأيام، الملاحظات، الكود، النوع) برسائلها.
- آلة الإرسال المزدوج (0 و1 وفق بيانات CSV الحيّة).
- بحث: بلا كود / كود خاطئ / استعادة صحيحة لآخر صف مطابق.
- عامل الخدمة نشط + إعادة تحميل دون اتصال تعمل من الكاش.
